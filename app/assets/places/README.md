# Fotos de los puntos del mapa

Una foto por punto, tomada por el comite. Van DENTRO del APK: no cuestan
nada, funcionan sin senal y son legalmente tuyas (las de Google no se
pueden guardar ni redistribuir).

Total de fotos: 130
## Como se nombran

El archivo debe llamarse EXACTAMENTE como el id del punto, con extension
.jpg, en esta misma carpeta. Si un punto no tiene foto, la app muestra su
icono de categoria y no pasa nada.

## Recomendaciones

- Horizontal (apaisada), aprox. 1200 x 600 px.
- Comprimir a ~150 KB cada una (con mas, el APK crece de mas).
- Que se vea la cancha/edificio completo, no un detalle.
